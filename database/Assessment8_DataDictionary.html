Assessment 8 Database Design

1. Table: Labstudent
Field NameData typeDescription
StdIdVARCHAR(10)PRIMARY KEY รหัสนักศึกษา
StdPasswordVARCHAR(30)รหัสผ่าน
StdNameVARCHAR(50)ชื่อนักศึกษา
StdLastnameVARCHAR(100)นามสกุลนักศึกษา
Picture
2. Table: Users
Field NameData typeDescription
UserIDINT (AUTO_INCREMENT)PRIMARY KEY รหัสผู้ใช้งาน
FirstNameVARCHAR(50)ชื่อ
LastNameVARCHAR(50)นามสกุล
EmailVARCHAR(100)อีเมล (UNIQUE)
PhoneNumberVARCHAR(20)เบอร์โทรศัพท์
PasswordVARCHAR(255)รหัสผ่าน (hashed)
RoleENUMCustomer / Staff / Accounting / Admin
IsActiveTINYINT(1)สถานะ: 1=ใช้งาน, 0=ระงับ
CreatedAtDATETIMEวันที่สร้างบัญชี
Picture
3. Table: Addresses
Field NameData typeDescription
AddressIDINT (AUTO_INCREMENT)PRIMARY KEY รหัสที่อยู่
UserIDINTFOREIGN KEY → Users.UserID
ReceiverNameVARCHAR(100)ชื่อผู้รับ
PhoneVARCHAR(20)เบอร์โทรผู้รับ
AddressLineVARCHAR(255)บ้านเลขที่ / ถนน / ซอย
DistrictVARCHAR(100)เขต / อำเภอ
ProvinceVARCHAR(100)จังหวัด
PostalCodeVARCHAR(10)รหัสไปรษณีย์
IsDefaultTINYINT(1)ที่อยู่เริ่มต้น: 1=ใช่, 0=ไม่ใช่
Picture
4. Table: Categories
Field NameData typeDescription
CategoryIDINT (AUTO_INCREMENT)PRIMARY KEY รหัสหมวดหมู่
CategoryNameVARCHAR(100)ชื่อหมวดหมู่สินค้า
DescriptionTEXTรายละเอียดหมวดหมู่
Picture
5. Table: Products
Field NameData typeDescription
ProductIDINT (AUTO_INCREMENT)PRIMARY KEY รหัสสินค้า
CategoryIDINTFOREIGN KEY → Categories.CategoryID
ProductNameVARCHAR(200)ชื่อสินค้า
DescriptionTEXTรายละเอียดสินค้า
BasePriceDECIMAL(10,2)ราคาเริ่มต้น (บาท)
ImageURLVARCHAR(500)URL รูปภาพสินค้า
IsActiveTINYINT(1)สถานะ: 1=เปิดขาย
CreatedAtDATETIMEวันที่เพิ่มสินค้า
Picture
6. Table: ProductVariants (SKU)
Field NameData typeDescription
VariantIDINT (AUTO_INCREMENT)PRIMARY KEY รหัส SKU
ProductIDINTFOREIGN KEY → Products.ProductID
ColorVARCHAR(50)สีของสินค้า
SizeVARCHAR(20)ไซส์ (XS/S/M/L/XL/XXL)
StockINTจำนวนสต็อกคงเหลือ
ExtraPriceDECIMAL(10,2)ราคาเพิ่มเติมจาก BasePrice
ImageURLVARCHAR(500)URL รูปภาพ SKU
Picture
7. Table: Promotions
Field NameData typeDescription
PromotionIDINT (AUTO_INCREMENT)PRIMARY KEY รหัสโปรโมชั่น
PromotionNameVARCHAR(200)ชื่อโปรโมชั่น
DiscountTypeENUMPercent / Fixed
DiscountValueDECIMAL(10,2)ค่าส่วนลด
MinOrderAmtDECIMAL(10,2)ยอดสั่งซื้อขั้นต่ำ (บาท)
CategoryIDINTFOREIGN KEY → Categories.CategoryID
StartDateDATETIMEวันเริ่มโปรโมชั่น
EndDateDATETIMEวันสิ้นสุดโปรโมชั่น
IsActiveTINYINT(1)สถานะ: 1=เปิดใช้งาน
Picture
8. Table: Coupons
Field NameData typeDescription
CouponIDINT (AUTO_INCREMENT)PRIMARY KEY รหัสคูปอง
CouponCodeVARCHAR(50)โค้ดส่วนลด (UNIQUE)
DiscountTypeENUMPercent / Fixed
DiscountValueDECIMAL(10,2)ค่าส่วนลด
MinOrderAmtDECIMAL(10,2)ยอดสั่งซื้อขั้นต่ำ
UsageLimitINTจำนวนครั้งสูงสุดที่ใช้ได้
UsedCountINTจำนวนครั้งที่ใช้ไปแล้ว
ExpiresAtDATETIMEวันหมดอายุ
IsActiveTINYINT(1)สถานะ: 1=ใช้งานได้
Picture
9. Table: Orders
Field NameData typeDescription
OrderIDINT (AUTO_INCREMENT)PRIMARY KEY รหัสคำสั่งซื้อ
UserIDINTFOREIGN KEY → Users.UserID
AddressIDINTFOREIGN KEY → Addresses.AddressID
SubtotalDECIMAL(10,2)ยอดรวมราคาสินค้า
ShippingFeeDECIMAL(10,2)ค่าจัดส่ง
DiscountAmtDECIMAL(10,2)ยอดส่วนลด
TotalAmountDECIMAL(10,2)ยอดรวมสุทธิ
PromotionIDINTFOREIGN KEY → Promotions.PromotionID
CouponIDINTFOREIGN KEY → Coupons.CouponID
StatusENUMPending / Verifying / Paid / Processing / Shipped / Completed / Cancelled / Refunded
PaymentMethodENUMBank Transfer / Credit Card / PromptPay
TrackingNumberVARCHAR(100)เลขพัสดุจัดส่ง
SlipImageURLVARCHAR(500)URL รูปสลิปโอนเงิน
OrderedAtDATETIMEวันเวลาสั่งซื้อ
UpdatedAtDATETIMEวันเวลาอัปเดตล่าสุด
Picture
10. Table: OrderItems
Field NameData typeDescription
OrderItemIDINT (AUTO_INCREMENT)PRIMARY KEY รหัสรายการสินค้า
OrderIDINTFOREIGN KEY → Orders.OrderID
VariantIDINTFOREIGN KEY → ProductVariants.VariantID
QuantityINTจำนวนที่สั่งซื้อ
UnitPriceDECIMAL(10,2)ราคาต่อชิ้น ณ เวลาสั่งซื้อ
Picture
11. Table: CartItems
Field NameData typeDescription
CartItemIDINT (AUTO_INCREMENT)PRIMARY KEY รหัสรายการตะกร้า
UserIDINTFOREIGN KEY → Users.UserID
VariantIDINTFOREIGN KEY → ProductVariants.VariantID
QuantityINTจำนวนสินค้าในตะกร้า
AddedAtDATETIMEวันเวลาที่เพิ่มลงตะกร้า
Picture
12. Table: Wishlists
Field NameData typeDescription
WishlistIDINT (AUTO_INCREMENT)PRIMARY KEY รหัส Wishlist
UserIDINTFOREIGN KEY → Users.UserID
ProductIDINTFOREIGN KEY → Products.ProductID
AddedAtDATETIMEวันเวลาที่เพิ่มรายการโปรด
Picture
13. Table: Reviews
Field NameData typeDescription
ReviewIDINT (AUTO_INCREMENT)PRIMARY KEY รหัสรีวิว
ProductIDINTFOREIGN KEY → Products.ProductID
UserIDINTFOREIGN KEY → Users.UserID
RatingTINYINTคะแนน 1-5 ดาว
CommentTEXTข้อความรีวิว
CreatedAtDATETIMEวันเวลาที่รีวิว
Picture
14. Table: Notifications
Field NameData typeDescription
NotificationIDINT (AUTO_INCREMENT)PRIMARY KEY รหัสการแจ้งเตือน
UserIDINTFOREIGN KEY → Users.UserID
TitleVARCHAR(200)หัวข้อการแจ้งเตือน
MessageTEXTเนื้อหาการแจ้งเตือน
IsReadTINYINT(1)สถานะ: 1=อ่านแล้ว, 0=ยังไม่อ่าน
CreatedAtDATETIMEวันเวลาที่แจ้งเตือน
Picture
